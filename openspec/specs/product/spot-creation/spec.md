# product/spot-creation Specification

## Purpose

Capability описывает модальное окно создания нового места погружения: состав полей формы, обязательность названия, отображение координат, блок загрузки фотографий и действия сохранения/отмены. Этот delta покрывает только UI; интеграция с API — отдельное изменение.

## Requirements

### Requirement: Модальное окно создания места

Система ДОЛЖНА (MUST) открывать модальное окно создания места поверх карты при клике по пустой точке карты. Подложка окна НЕ ДОЛЖНА (MUST NOT) блокировать взаимодействие с картой: клик по карте переставляет маркер (см. `product/map`). Система ДОЛЖНА (MUST) предоставлять закрытие окна по кнопке «Отмена», крестику и клавише Esc. При открытом окне создания ДОЛЖЕН (MUST) отображаться временный маркер в текущей точке создания.

#### Scenario: [P0] Открытие модального окна

- **GIVEN** карта загружена, модальное окно закрыто
- **WHEN** пользователь кликает по пустой точке карты
- **THEN** поверх карты открывается модальное окно создания места, на карте появляется временный маркер в точке клика

#### Scenario: [P1] Закрытие без сохранения

- **GIVEN** модальное окно создания места открыто, поля частично заполнены
- **WHEN** пользователь нажимает «Отмена», крестик или Esc
- **THEN** окно закрывается, временный маркер исчезает, введённые данные отбрасываются

### Requirement: Поле наименования

Система ДОЛЖНА (MUST) показывать в форме текстовое поле «Наименование». Наименование — единственное обязательное поле: кнопка «Сохранить» ДОЛЖНА (MUST) быть неактивна, пока наименование пустое или состоит только из пробельных символов.

#### Scenario: [P0] Пустое наименование блокирует сохранение

- **GIVEN** модальное окно создания места открыто, поле наименования пустое
- **WHEN** пользователь смотрит на кнопку «Сохранить»
- **THEN** кнопка «Сохранить» неактивна

#### Scenario: [P0] Заполненное наименование разрешает сохранение

- **GIVEN** модальное окно создания места открыто
- **WHEN** пользователь вводит непустое наименование (не только пробелы)
- **THEN** кнопка «Сохранить» становится активна

### Requirement: Отображение координат

Система ДОЛЖНА (MUST) отображать в форме координаты (широту и долготу) выбранной точки в режиме «только чтение». Система НЕ ДОЛЖНА (MUST NOT) предоставлять ручной ввод или редактирование координат текстом. При перестановке маркера кликом по карте отображаемые координаты ДОЛЖНЫ (MUST) обновляться.

#### Scenario: [P0] Координаты отображаются и не редактируются

- **GIVEN** модальное окно создания места открыто
- **WHEN** пользователь смотрит на блок координат
- **THEN** отображаются широта и долгота точки клика, поля недоступны для редактирования

#### Scenario: [P0] Обновление координат при перестановке маркера

- **GIVEN** модальное окно создания места открыто
- **WHEN** пользователь кликает по другой пустой точке карты
- **THEN** временный маркер перемещается в новую точку, координаты в форме обновляются, введённые значения остальных полей сохраняются

### Requirement: Поле описания

Система ДОЛЖНА (MUST) показывать в форме опциональное многострочное текстовое поле «Описание». Пустое описание НЕ ДОЛЖНО (MUST NOT) блокировать сохранение.

#### Scenario: [P1] Сохранение без описания

- **GIVEN** модальное окно открыто, наименование заполнено, описание пустое
- **WHEN** пользователь нажимает «Сохранить»
- **THEN** сохранение выполняется, отсутствие описания не является ошибкой

### Requirement: Блок загрузки фотографий

Система ДОЛЖНА (MUST) показывать в форме блок загрузки фотографий: выбор до 10 файлов за одну загрузку, предпросмотр выбранных фотографий и возможность удалить фотографию из списка до сохранения. Фотографии опциональны: их отсутствие НЕ ДОЛЖНО (MUST NOT) блокировать сохранение. При превышении лимита в 10 файлов система ДОЛЖНА (MUST) отклонить лишние файлы и показать понятное сообщение.

#### Scenario: [P0] Выбор и предпросмотр фотографий

- **GIVEN** модальное окно создания места открыто
- **WHEN** пользователь выбирает несколько фотографий (не более 10)
- **THEN** выбранные фотографии отображаются в блоке предпросмотра

#### Scenario: [P1] Удаление фотографии из списка

- **GIVEN** в блоке загрузки есть выбранные фотографии
- **WHEN** пользователь удаляет одну из них
- **THEN** фотография исчезает из предпросмотра и не будет отправлена при сохранении

#### Scenario: [P1] Превышение лимита в 10 файлов

- **GIVEN** в блоке загрузки уже выбрано 10 фотографий
- **WHEN** пользователь пытается добавить ещё
- **THEN** лишние файлы отклоняются, пользователю показывается сообщение о лимите

### Requirement: Действие сохранения (без API)

Система ДОЛЖНА (MUST) предоставлять кнопку «Сохранить». В рамках этого изменения сохранение НЕ ДОЛЖНО (MUST NOT) обращаться к API: по нажатию форма валидируется, собранные данные (наименование, координаты, описание, список файлов) передаются в обработчик-заглушку, окно закрывается, временный маркер исчезает. Интеграция с API — отдельное изменение.

#### Scenario: [P0] Сохранение закрывает форму

- **GIVEN** модальное окно открыто, наименование заполнено
- **WHEN** пользователь нажимает «Сохранить»
- **THEN** данные формы передаются в обработчик-заглушку, окно закрывается, временный маркер исчезает, новый маркер места на карте не появляется (до появления API)
