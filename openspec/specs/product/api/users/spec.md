# users Specification

## Purpose

Capability `users` закрывает хранение пользователей в базе данных и выдачу информации об авторизованном (текущем) пользователе через REST API.

## Requirements

### Requirement: Хранение пользователей в базе данных

Система ДОЛЖНА (MUST) хранить пользователей в таблице `users` в PostgreSQL. Таблица ДОЛЖНА (MUST) содержать как минимум: уникальный идентификатор пользователя, отображаемое имя и метки времени создания и обновления записи. Таблица ДОЛЖНА (MUST) создаваться миграцией Alembic.

#### Scenario: [P0] Миграция создаёт таблицу пользователей

- **GIVEN** база данных без таблицы `users`
- **WHEN** применяются миграции Alembic
- **THEN** в базе данных существует таблица `users` с обязательными полями

#### Scenario: [P1] Откат миграции удаляет таблицу пользователей

- **GIVEN** миграция, создающая таблицу `users`, применена
- **WHEN** выполняется откат этой миграции
- **THEN** таблица `users` отсутствует в базе данных

### Requirement: Эндпоинт информации об авторизованном пользователе

Система ДОЛЖНА (MUST) предоставлять REST-эндпоинт `GET /users/me`, возвращающий информацию о текущем (авторизованном) пользователе. Ответ ДОЛЖЕН (MUST) содержать идентификатор и отображаемое имя пользователя и НЕ ДОЛЖЕН (MUST NOT) раскрывать служебные поля хранения, не предназначенные для клиента. Механизм определения текущего пользователя ДОЛЖЕН (MUST) быть вынесен в подменяемую зависимость, чтобы будущая схема аутентификации подключалась без изменения контракта эндпоинта.

#### Scenario: [P0] Успешное получение информации о текущем пользователе

- **GIVEN** текущий пользователь определён и существует в базе данных
- **WHEN** выполняется запрос `GET /users/me`
- **THEN** возвращается ответ 200 с идентификатором и отображаемым именем текущего пользователя

#### Scenario: [P1] Текущий пользователь не найден в базе данных

- **GIVEN** механизм определения текущего пользователя указывает на пользователя, отсутствующего в базе данных
- **WHEN** выполняется запрос `GET /users/me`
- **THEN** возвращается ответ 404 с информативным описанием ошибки
