# Spec Delta

## Purpose

Capability описывает главное меню приложения: сворачиваемый сайдбар поверх карты с иконками разделов («Мои места», «Мое снаряжение», «Настройки») и панель выбранного раздела, открывающуюся поверх карты.

## ADDED Requirements

### Requirement: Сайдбар главного меню

Система ДОЛЖНА (MUST) постоянно отображать поверх карты слева узкий сайдбар главного меню с иконками разделов. В свёрнутом состоянии сайдбар ДОЛЖЕН (MUST) показывать только иконки; в развёрнутом — иконки с подписями разделов. Сайдбар ДОЛЖЕН (MUST) содержать стрелку-переключатель, разворачивающую и сворачивающую его.

#### Scenario: [P0] Отображение сайдбара

- **GIVEN** главный экран с картой загружен
- **WHEN** пользователь смотрит на экран
- **THEN** слева поверх карты отображается узкий сайдбар с иконками разделов и стрелкой-переключателем

#### Scenario: [P0] Разворачивание сайдбара

- **GIVEN** сайдбар свёрнут, видны только иконки
- **WHEN** пользователь нажимает стрелку-переключатель
- **THEN** сайдбар разворачивается: рядом с иконками появляются подписи разделов

#### Scenario: [P1] Сворачивание сайдбара

- **GIVEN** сайдбар развёрнут, видны иконки и подписи
- **WHEN** пользователь нажимает стрелку-переключатель
- **THEN** сайдбар сворачивается до узкой полосы с иконками

### Requirement: Разделы главного меню

Сайдбар ДОЛЖЕН (MUST) содержать ровно три раздела: «Мои места», «Мое снаряжение», «Настройки», каждый со своей иконкой. Каждый раздел ДОЛЖЕН (MUST) открывать соответствующую панель при клике. Состояние сайдбара (свёрнут/развёрнут) при выборе раздела НЕ ДОЛЖНО (MUST NOT) меняться.

#### Scenario: [P0] Состав разделов

- **GIVEN** главный экран с картой загружен
- **WHEN** пользователь смотрит на сайдбар
- **THEN** в сайдбаре есть разделы «Мои места», «Мое снаряжение», «Настройки» и только они, у каждого своя иконка

#### Scenario: [P0] Выбор раздела

- **GIVEN** панели на карте закрыты
- **WHEN** пользователь кликает по иконке «Мое снаряжение»
- **THEN** поверх карты открывается панель раздела «Мое снаряжение», сайдбар остаётся в текущем состоянии (свёрнут/развёрнут)

### Requirement: Панель раздела поверх карты

Система ДОЛЖНА (MUST) открывать выбранный раздел панелью поверх карты, не уводя пользователя с главного экрана. Одновременно МОЖЕТ (MAY) быть открыта не более одной панели раздела. Панель ДОЛЖНА (MUST) закрываться по явному действию пользователя (кнопка закрытия); карта при этом ДОЛЖНА (MUST) сохранять текущее положение и масштаб. Пока содержимое разделов не реализовано, панель каждого раздела ДОЛЖНА (MUST) отображать заглушку с названием раздела.

#### Scenario: [P0] Открытие панели раздела

- **GIVEN** панели на карте закрыты
- **WHEN** пользователь выбирает раздел «Настройки» в сайдбаре
- **THEN** поверх карты открывается панель раздела «Настройки» с заглушкой-контентом, карта остаётся видна и доступна

#### Scenario: [P1] Закрытие панели раздела

- **GIVEN** панель раздела открыта
- **WHEN** пользователь нажимает кнопку закрытия панели
- **THEN** панель закрывается, карта остаётся в текущем положении и масштабе

#### Scenario: [P1] Переключение между разделами

- **GIVEN** открыта панель раздела «Мои места»
- **WHEN** пользователь выбирает в сайдбаре раздел «Настройки»
- **THEN** панель «Мои места» заменяется панелью «Настройки»
