# Spec Delta

## MODIFIED Requirements

### Requirement: Клик по пустой точке карты

Система ДОЛЖНА (MUST) при клике по пустой точке карты (не по маркеру) получать географические координаты точки клика и открывать поверх карты панель создания нового места с этими координатами. При этом любая открытая панель (места, создания места или раздела главного меню) ДОЛЖНА (MUST) заменяться панелью создания места: одновременно на карте открыта не более одной панели.

#### Scenario: [P0] Клик по пустой точке открывает создание места

- **GIVEN** карта загружена, панели закрыты
- **WHEN** пользователь кликает по точке карты, где нет маркера
- **THEN** поверх карты открывается панель создания места, координаты точки клика зафиксированы для нового места

#### Scenario: [P1] Клик по карте при открытой панели

- **GIVEN** открыта панель места, создания места или раздела главного меню
- **WHEN** пользователь кликает по пустой точке карты
- **THEN** открытая панель заменяется панелью создания места с новыми координатами
