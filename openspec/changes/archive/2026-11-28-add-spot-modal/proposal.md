# Proposal

## Мотивация

Сейчас клик по пустой точке карты открывает панель-заглушку `CreateSpotPanel`, которая показывает только координаты и текст «Форма создания места появится в этапе "Карта + Spot"». Создать место через UI невозможно — это ключевой сценарий MVP (этап 2 «Карта + Spot» по AGENTS.md).

Это изменение — первый шаг этапа: проектируем и реализуем интерфейс создания точки (модальное окно с формой) без интеграции с API. Сохранение данных на бэкенд — следующее изменение.

## Пользовательские сценарии

Я как пользователь (дайвер, владелец журнала):

- хочу кликнуть по пустой точке карты и увидеть форму создания нового места, чтобы зафиксировать локацию погружения.
- хочу видеть в форме координаты выбранной точки, чтобы убедиться, что кликнул куда нужно.
- хочу до сохранения переставить точку повторным кликом по карте, чтобы исправить промах мимо нужной локации без закрытия формы.
- хочу ввести название (и при желании описание, фото) и сохранить место, при этом форма не должна давать сохранить место без названия.
- хочу отменить создание и закрыть форму, чтобы ничего не менять.

## Что меняется

Добавлено:

- Модальное окно создания места поверх карты (вместо текущей боковой панели-заглушки) с полями:
  - **Наименование** — текстовое поле, единственное обязательное; кнопка «Сохранить» неактивна, пока название пустое (с учётом trim).
  - **Координаты** — отображаются read-only (широта/долгота выбранной точки), ручной ввод невозможен.
  - **Описание** — опциональное многострочное текстовое поле (в будущем — описание места в целом).
  - **Блок загрузки фотографий** — выбор до 10 файлов за раз, предпросмотр выбранных фото, удаление из списка до сохранения.
- Перестановка маркера нового места повторным кликом по карте, пока открыта форма создания: координаты в форме обновляются.
- Временный маркер на карте в точке создания, пока форма открыта.
- Кнопки «Сохранить» и «Отмена»; закрытие по «Отмена», крестику и Esc. Подложка визуально затемняет карту, но не блокирует клики по ней — иначе конфликтовала бы с перестановкой маркера кликом (подробности в design.md).

Изменено:

- Клик по пустой точке карты теперь открывает модальное окно создания места, а не боковую панель (уточнение AGENTS.md: формы — модальные окна поверх карты, а не панели; AGENTS.md будет обновлён).
- Поведение клика по карте при открытой форме создания: раньше панель заменялась новой с новыми координатами, теперь клик переставляет маркер в рамках той же формы.

Удалено:

- Панель-заглушка `CreateSpotPanel` в текущем виде (заменяется модальным окном).

Явно отложено за пределы этого изменения:

- Интеграция с API: создание места на бэкенде, загрузка фото в хранилище. «Сохранить» в этом изменении — заглушка (валидация + закрытие без персистентности), реальная отправка — следующим шагом.
- Редактирование и удаление места, карточка места с галереей, журнал погружений.
- Мобильная адаптация модального окна.

## Возможности

### Новые возможности

- `product/spot-creation`: модальное окно создания места — поля формы, обязательность названия, read-only координаты, блок загрузки фото, сохранение/отмена.

### Изменённые возможности

- `product/map`: требование «Клик по пустой точке карты» — открытие модального окна вместо панели; клик по карте при открытой форме создания переставляет маркер, а не заменяет панель.

## Влияние

- **Код**: только фронтенд (`frontend/src/features/map/`): замена `CreateSpotPanel` на модальное окно, изменение обработчика клика в `MapScreen`, стили модалки. Новых зависимостей не планируется (нативный `<dialog>` или собственная реализация поверх карты — решение в design.md).
- **API**: не затрагивается в этом изменении; `POST /spots` и загрузка фото — следующим шагом.
- **Данные**: персистентности нет — созданные в форме данные не сохраняются до появления API-интеграции. Пользовательский эффект: форму можно заполнить и «сохранить», но место на карте не появится — это осознанное промежуточное состояние первого шага.
- **Документация**: AGENTS.md — обновить формулировку «карточка и формы — панели поверх карты» на модальное окно для формы создания места.
