# Spec Delta

## MODIFIED Requirements

### Requirement: Клик по пустой точке карты

Система ДОЛЖНА (MUST) при клике по пустой точке карты (не по маркеру) получать географические координаты точки клика и открывать поверх карты модальное окно создания нового места с этими координатами (см. capability `product/spot-creation`). При этом любая открытая панель (места или раздела главного меню) ДОЛЖНА (MUST) заменяться модальным окном создания места: одновременно на карте открыт не более один элемент поверх (панель или модальное окно). Пока открыто модальное окно создания места, клик по пустой точке карты ДОЛЖЕН (MUST) переставлять маркер нового места в точку клика, не закрывая окно и не сбрасывая введённые данные формы.

#### Scenario: [P0] Клик по пустой точке открывает создание места

- **GIVEN** карта загружена, панели и модальные окна закрыты
- **WHEN** пользователь кликает по точке карты, где нет маркера
- **THEN** поверх карты открывается модальное окно создания места, координаты точки клика зафиксированы для нового места

#### Scenario: [P1] Клик по карте при открытой панели

- **GIVEN** открыта панель места или раздела главного меню
- **WHEN** пользователь кликает по пустой точке карты
- **THEN** открытая панель заменяется модальным окном создания места с координатами точки клика

#### Scenario: [P0] Клик по карте при открытом окне создания переставляет маркер

- **GIVEN** открыто модальное окно создания места, поля формы частично заполнены
- **WHEN** пользователь кликает по другой пустой точке карты
- **THEN** маркер нового места переставляется в точку клика, координаты в форме обновляются, введённые данные сохраняются, окно остаётся открытым
