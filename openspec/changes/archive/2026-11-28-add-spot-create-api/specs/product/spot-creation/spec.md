# Spec Delta

## ADDED Requirements

### Requirement: Сохранение места через API

Система ДОЛЖНА (MUST) по нажатию кнопки «Сохранить» отправлять данные формы (наименование, координаты, описание) в `POST /spots`. Пока запрос выполняется, система ДОЛЖНА (MUST) блокировать повторную отправку. После успешного ответа система ДОЛЖНА (MUST) закрыть модальное окно, убрать временный маркер и перезапросить список спотов так, чтобы новое место появилось маркером на карте. При ошибке запроса система ДОЛЖНА (MUST) оставить окно открытым с введёнными данными и показать сообщение об ошибке. Фотографии, выбранные в форме, в этом изменении НЕ отправляются (загрузка фото — отдельное изменение).

#### Scenario: [P0] Успешное сохранение показывает место на карте

- **GIVEN** модальное окно создания открыто, наименование заполнено, API доступен
- **WHEN** пользователь нажимает «Сохранить»
- **THEN** отправляется `POST /spots` с наименованием, координатами и описанием из формы; после ответа 201 окно закрывается, временный маркер исчезает, и на карте появляется маркер нового места в его координатах

#### Scenario: [P0] Новое место переживает перезагрузку страницы

- **GIVEN** пользователь успешно создал место через модальное окно
- **WHEN** пользователь перезагружает страницу
- **THEN** созданное место отображается маркером на карте вместе с остальными спотами

#### Scenario: [P1] Ошибка сохранения не теряет введённые данные

- **GIVEN** модальное окно создания открыто, поля заполнены, API вернул ошибку или недоступен
- **WHEN** пользователь нажимает «Сохранить»
- **THEN** окно остаётся открытым, введённые значения полей сохраняются, отображается сообщение об ошибке, пользователь может повторить сохранение или отменить

#### Scenario: [P1] Повторная отправка заблокирована во время запроса

- **GIVEN** модальное окно создания открыто, наименование заполнено, запрос `POST /spots` ещё выполняется
- **WHEN** пользователь нажимает «Сохранить» повторно
- **THEN** повторный запрос не отправляется

## REMOVED Requirements

### Requirement: Действие сохранения (без API)

**Reason**: заглушка сохранения заменяется реальной интеграцией с `POST /spots` — данные формы больше не отбрасываются, окно закрывается только после успешного создания.

**Migration**: поведение «Сохранить» описывает новое требование «Сохранение места через API»; валидация наименования и блокировка кнопки при пустом названии остаются без изменений (требование «Поле наименования»).
