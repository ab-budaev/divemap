# Spec Delta

## Purpose

Capability описывает интерактивную Яндекс.Карту как основу главного экрана divemap: отображение карты, маркеры мест погружений, клики по карте и панели поверх неё.

## ADDED Requirements

### Requirement: Интерактивная карта на главном экране

Система ДОЛЖНА (MUST) отображать на главном экране интерактивную Яндекс.Карту, занимающую основную область экрана, вместо текущей заглушки. Карта ДОЛЖНА (MUST) поддерживать панорамирование и масштабирование. Система ДОЛЖНА (MUST) загружать картографический API с API-ключом, задаваемым через конфигурацию окружения, а не захардкоженным в коде.

#### Scenario: [P0] Открытие главного экрана

- **GIVEN** приложение запущено и API-ключ карт настроен
- **WHEN** пользователь открывает главную страницу
- **THEN** отображается интерактивная Яндекс.Карта, доступны панорамирование и зум

#### Scenario: [P0] Отсутствует или невалиден API-ключ

- **GIVEN** API-ключ карт не задан или невалиден
- **WHEN** пользователь открывает главную страницу
- **THEN** вместо карты отображается понятное сообщение об ошибке конфигурации, приложение не падает с белым экраном

### Requirement: Маркеры мест на карте

Система ДОЛЖНА (MUST) отображать место погружения маркером на карте по его координатам. Система ДОЛЖНА (MUST) открывать панель с информацией о месте поверх карты при клике на маркер. Панель ДОЛЖНА (MUST) закрываться по явному действию пользователя.

#### Scenario: [P0] Отображение маркеров

- **GIVEN** существует несколько мест с координатами
- **WHEN** главный экран с картой загружен
- **THEN** каждое место отображается маркером в точке с его координатами

#### Scenario: [P0] Клик по маркеру открывает панель места

- **GIVEN** на карте отображаются маркеры мест
- **WHEN** пользователь кликает по маркеру
- **THEN** поверх карты открывается панель с информацией об этом месте

#### Scenario: [P1] Закрытие панели места

- **GIVEN** панель места открыта
- **WHEN** пользователь нажимает кнопку закрытия панели
- **THEN** панель закрывается, карта остаётся в текущем положении и масштабе

### Requirement: Клик по пустой точке карты

Система ДОЛЖНА (MUST) при клике по пустой точке карты (не по маркеру) получать географические координаты точки клика и открывать поверх карты панель создания нового места с этими координатами.

#### Scenario: [P0] Клик по пустой точке открывает создание места

- **GIVEN** карта загружена, панели закрыты
- **WHEN** пользователь кликает по точке карты, где нет маркера
- **THEN** поверх карты открывается панель создания места, координаты точки клика зафиксированы для нового места

#### Scenario: [P1] Клик по карте при открытой панели

- **GIVEN** панель места или создания места открыта
- **WHEN** пользователь кликает по пустой точке карты
- **THEN** открытая панель заменяется панелью создания места с новыми координатами
