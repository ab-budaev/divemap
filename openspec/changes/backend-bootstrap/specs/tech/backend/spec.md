# Spec Delta

## Purpose

Capability закрывает базовую эксплуатационную работоспособность divemap в локальном окружении: сервис отчитывается о своём состоянии, а окружение поднимается одной командой без потери данных.

## ADDED Requirements

### Requirement: Health-check эндпоинт сервиса

Система ДОЛЖНА (MUST) предоставлять служебный health-check эндпоинт, отчитывающийся о состоянии сервиса.

#### Scenario: [P0] Сервис отвечает на health-check запрос

- **GIVEN** сервис запущен
- **WHEN** запрашивается health-check эндпоинт
- **THEN** ответ сообщает об успешном состоянии сервиса

### Requirement: Запуск локального окружения одной командой и сохранность данных

Система ДОЛЖНА (MUST) подниматься локально одной командой (приложение и база данных) и ДОЛЖНА (MUST) сохранять данные при перезапуске контейнеров.

#### Scenario: [P0] Чистый подъём с нуля

- **GIVEN** свежий клон репозитория с заполненным `.env`
- **WHEN** выполняется команда запуска
- **THEN** приложение и PostgreSQL работают, а health-check эндпоинт отвечает успехом

#### Scenario: [P1] Перезапуск контейнеров

- **GIVEN** окружение запущено и в базе данных есть данные
- **WHEN** контейнеры пересоздаются
- **THEN** данные сохраняются и health-check эндпоинт снова отвечает успехом
