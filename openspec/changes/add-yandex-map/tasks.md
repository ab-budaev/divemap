## 1. Подключение Яндекс.Карт к фронтенду

- [x] 1.1 [Frontend] Установить dev-зависимость `@yandex/ymaps3-types` и настроить типизацию глобального `ymaps3`. Критерий приёмки: `npm run build` (включает `tsc -b`) проходит без ошибок типов при обращении к `ymaps3`.
- [x] 1.2 [Frontend] Реализовать загрузку JS API v3 (скрипт `api-maps.yandex.ru/v3` с ключом из `VITE_YANDEX_MAPS_API_KEY`) и reactify-интеграцию (`@yandex/ymaps3-reactify` через `ymaps3.import`, `bindTo(React, ReactDOM)`) в одном компоненте-обёртке `features/map`. Критерий приёмки: компонент экспортирует React-компоненты карты, загрузка происходит один раз, ошибка загрузки (нет ключа / невалидный ключ) перехватывается и передаётся наружу как состояние ошибки.
- [x] 1.3 [Frontend] Добавить `VITE_YANDEX_MAPS_API_KEY` в конфигурацию окружения: чтение через `import.meta.env` из `frontend/.env` (покрыт `.gitignore`, ключ уже положен владельцем), плюс `.env.example` с описанием для новых окружений. Критерий приёмки: без переменной приложение собирается и показывает экран ошибки конфигурации, с переменной — карту.

## 3. Маркеры и панели

- [x] 3.4 [Frontend] Управление панелями: закрытие по кнопке, замена открытой панели новой при клике по другому маркеру/точке, карта не перемонтируется и не сбрасывает позицию. Критерий приёмки: сценарии открытия/закрытия/замены панелей работают, положение и зум карты сохраняются.
