# Proposal

## Мотивация

Сейчас на главном экране вместо карты — заглушка (проверка health-check). Карта — ядро продукта: весь user flow MVP (добавление места кликом, маркеры мест, карточка поверх карты) строится вокруг интерактивной карты. Без неё нельзя начинать кусок 2 («Карта + Spot») из дорожной карты MVP.

Решено использовать Яндекс.Карты, но не как ссылку/iframe на maps.yandex.ru, а как встраиваемую картографическую подложку (JavaScript API), поверх которой приложение рисует собственный UI: маркеры мест, клики по пустым точкам, панели и модальные окна.

## Пользовательские сценарии

Я как пользователь:

- хочу видеть интерактивную карту на главном экране, чтобы ориентироваться географически;
- хочу видеть маркеры сохранённых мест погружений на карте, чтобы быстро находить нужное место;
- хочу кликнуть по маркеру и увидеть панель с информацией о месте поверх карты, чтобы не уходить с карты;
- хочу кликнуть по пустой точке карты и получить форму создания нового места с координатами из клика, чтобы добавлять места без ручного ввода координат.

Я как разработчик:

- хочу использовать официально поддерживаемую библиотеку карт с React-интеграцией, чтобы не зависеть от заброшенных обёрток и иметь типизацию.

## Что меняется

Добавлено:

- Интерактивная Яндекс.Карта на главном экране вместо заглушки: панорамирование, зум, стандартные элементы управления.
- Маркеры мест погружений на карте (пока на тестовых данных, пока нет API мест).
- Клик по маркеру открывает панель поверх карты (заготовка карточки места).
- Клик по пустой точке карты возвращает координаты и открывает панель создания места (заготовка формы).
- Инфраструктура подключения карты: загрузка API с ключом, конфигурация ключа через переменные окружения.

Изменено:

- Главный экран приложения: заглушка заменяется полноэкранной картой с поверхностью для панелей.

Удалено:

- Ничего.

Явно отложено за пределы этого изменения:

- Привязка маркеров к реальному API мест (будет в куске «Карта + Spot» вместе с бэкендом мест).
- Полноценные формы места и карточка места — здесь только заготовки панелей, открываемых с карты.
- Сайдбар со списком мест, кластеризация маркеров, геокодирование и поиск по карте.
- Кастомный дизайн маркеров (иконки дайвинга) — используются стандартные/простые маркеры.

## Возможности

### Новые возможности

- `product/map`: интерактивная Яндекс.Карта как основа главного экрана — отображение, навигация, маркеры мест, клик по пустой точке с координатами, панели поверх карты.

### Изменённые возможности

- Нет (существующие требования `tech/frontend` не меняются).

## Влияние

- **Frontend**: новая зависимость — Яндекс.Карты JS API v3 (`@yandex/ymaps3-types` и официальный модуль react-интеграции); новая структура `frontend/src/features/map/`; переработка `App.tsx` (карта как главный экран).
- **Конфигурация**: потребуется API-ключ Яндекс.Карт (получается в кабинете разработчика, бесплатный тариф), передаётся через переменную окружения `VITE_YANDEX_MAPS_API_KEY`; ключ нужно будет добавить в локальное окружение и в деплой.
- **Backend**: не затрагивается.
- **Пользователи**: вместо заглушки видят рабочую карту; данные мест пока демонстрационные.
